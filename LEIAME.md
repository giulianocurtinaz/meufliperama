# meufliperama.com.br

Portal de entrada do projeto Meu Fliperama — um fliperama aberto onde qualquer pessoa cria jogos em Python e publica para todo mundo jogar. Os jogos vão rodar no Infonotas do servidor de casa (macserver); este repositório é só a vitrine pública.

## Arquivos
- `index.html` — textos da página (seções: Como funciona, Quem pode publicar, Placar de lançamento)
- `estilo.css` — visual arcade retrô
- `demo.js` — o joguinho do gabinete (FICHA + START para jogar; setas/A-D e espaço)
- `fontes/` — Press Start 2P e VT323 hospedadas aqui mesmo (licença OFL)
- `CNAME` — domínio meufliperama.com.br

## Publicação
GitHub Pages servindo a branch `main` (pasta raiz). Cada push na `main` publica sozinho.

Para atualizar o andamento, edite a tabela "Placar de lançamento" no `index.html`.

## Privacidade
Sem cookies, sem rastreamento, sem recursos de terceiros.
